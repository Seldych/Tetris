# Тетрис

Классическая игра Тетрис на чистом HTML/CSS/JavaScript с использованием Canvas.

## Особенности

- Полноценная механика: вращение, ускорение, сброс
- Ghost piece (тень падающей фигуры)
- Превью следующей фигуры
- Система очков и уровней (ускорение с каждым уровнем)
- Анимация вспышки при очистке линий
- Wall-kick при вращении у стен
- Призрачная фигура (ghost piece)
- Адаптивная верстка (десктоп + мобильные)
- Тёмная тема с неоновым дизайном
- CSS custom properties для цветовой схемы

## Управление

| Клавиша | Действие      |
|---------|---------------|
| ← →     | Движение      |
| ↑       | Поворот       |
| ↓       | Ускорение     |
| Пробел  | Сброс         |
| P       | Пауза         |
| R       | Перезапуск    |

## Запуск

Просто откройте `index.html` в браузере.

## Структура проекта

- `index.html` — единственный файл игры (HTML + CSS + JS)
- `AGENTS.md` — конфигурация для opencode-агентов
- `README.md` — этот файл
